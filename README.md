# HistaScan

Erster MVP einer Expo-App für:

- Histamin-Lebensmittelbewertung
- Kalorien- und Makrotracking
- Stimmung und tägliche Check-ins
- Symptomtagebuch
- lokale Datenspeicherung auf dem Gerät

## Lokal starten

```bash
npm install
npx expo start
```

Anschließend den QR-Code mit Expo Go scannen.

## Hinweis

Die App befindet sich im Prototypenstadium und ersetzt keine medizinische Diagnose oder Beratung.
